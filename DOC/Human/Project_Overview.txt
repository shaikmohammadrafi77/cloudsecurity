Cloudescurity Project Overview
Date: April 08, 2026

1. Project Summary
Cloudescurity is a secure, full-stack file storage platform that provides encrypted file upload, download, sharing, and auditing. It combines a modern Next.js frontend with an Express API, MongoDB for metadata, and AWS S3 for encrypted blob storage. The system emphasizes zero-trust vault encryption, MFA, and security logging.

2. Objectives
- Protect user files with strong encryption at rest.
- Provide secure authentication with optional 2FA.
- Support file sharing with controlled access.
- Maintain audit trails for security events.
- Offer a responsive, modern UI for vault management.

3. Scope (Start to End)
- User registration and login
- Multi-factor authentication (TOTP)
- File upload, download, delete, restore
- Folder management
- Share links with optional controls
- Security logging and dashboard analytics
- Password reset via SMTP
- Mock mode for local development without MongoDB

4. System Architecture (High-Level)
- Frontend: Next.js (App Router), React 19, Tailwind CSS, Framer Motion
- Backend: Node.js, Express, Mongoose
- Storage: AWS S3 (encrypted files), MongoDB (metadata)
- Auth: JWT, TOTP (otplib)
- Security: AES-256 encryption (CBC/GCM), rate limiting, Helmet
